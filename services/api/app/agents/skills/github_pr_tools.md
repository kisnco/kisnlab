# Outils GitHub PR (lecture seule)

- `gh_pr_list(repo, state)` : lister les PRs.
- `gh_pr_get(repo, number)` : metadata d'une PR.
- `gh_pr_diff(repo, number)` : diff unifié.

Pour analyser une PR : lis d'abord le diff (`gh_pr_diff`), puis rédige tes
observations en markdown structuré dans ta réponse texte. Tu **ne postes
jamais** sur GitHub : tu n'as pas d'outil d'écriture. Si Mélodie veut
publier une review, c'est une action manuelle ou un skill séparé avec
validation.
